# Salesforce Work Portfolio — Aditya Kopalli

A minimal, zero-build static site cataloguing my Salesforce engineering work across
**Scoring**, **MuleSoft integration**, **Agentforce**, **IAM**, and **POCs**. Every item
opens to its low-level design, test plan, and setup steps. The overview shows live
figures: a GitHub-style commit heatmap, company tenure, and GUS work-item activity.

## Run locally

No build step. Just serve the folder:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Edit content

Portfolio content lives in [`assets/js/data.js`](assets/js/data.js) — add an item to the
relevant area's `items[]` array.

## Stats (commits, tenure, GUS)

The overview reads [`assets/data/stats.json`](assets/data/stats.json), regenerated by
[`scripts/update-stats.mjs`](scripts/update-stats.mjs):

- **Commits** — scans local git clones under `$HOME`, deduped by SHA, bucketed into a
  day-by-day calendar and grouped by host (git.soma / core / github). Reads local
  history, so it works offline even when GHE tokens are expired.
- **Tenure** — computed from `TENURE_START` in the script (edit this one line if the
  start date is wrong).
- **GUS** — queries `ADM_Work__c` on the `gus` org via the `sf` CLI for totals + a
  monthly timeline.
- **PRs** — best-effort `gh search prs` per host; only populated for hosts with a valid
  token. Refresh internal tokens with `gh auth refresh -h git.soma.salesforce.com` and
  `-h gitcore.soma.salesforce.com` to fill these in.

Run it by hand:

```sh
node scripts/update-stats.mjs          # write assets/data/stats.json
node scripts/update-stats.mjs --push   # also commit + push
```

### Daily refresh

A launchd agent runs the refresh every day at 09:20 local time. It has to run on this
machine — the internal sources (git.soma/core clones, GUS) aren't reachable from a cloud
runner, so a GitHub Action can't do it.

```sh
# installed at:
~/Library/LaunchAgents/com.akopalli.portfolio-stats.plist   # schedule
scripts/refresh.sh                                           # wrapper it runs
scripts/refresh.log                                          # run output

launchctl list | grep portfolio-stats     # confirm it's loaded
launchctl start com.akopalli.portfolio-stats   # run once now
```

## Host on GitHub Pages

1. Push to `https://github.com/KopalliAditya/salesforce-portfolio`.
2. Settings → Pages → Source: `main` branch, `/root`.
3. Site publishes at `https://kopalliaditya.github.io/salesforce-portfolio/`.

## Structure

```
index.html             # shell: identity rail + routed content
assets/css/style.css    # dark/light theme, ledger list, heatmap, bar graph
assets/js/data.js       # ← all portfolio content lives here
assets/js/app.js        # routing, rendering, heatmap + GUS graph
assets/data/stats.json  # generated figures (commits/tenure/GUS)
scripts/update-stats.mjs # regenerates stats.json
scripts/refresh.sh      # launchd wrapper for the daily run
```
